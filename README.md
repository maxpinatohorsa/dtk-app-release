# dtk-app — release

Questo repository contiene solo gli installer di **dtk-app** per Windows e il file
`latest.json` con cui l'app si aggiorna da sola. Non contiene codice.

L'app funziona insieme a `dtk`, che si installa seguendo il README del repository
del toolkit. Senza `dtk` e senza le credenziali di un tenant l'app non fa niente.

Segnalazioni e richieste non si aprono qui: dall'app, "Segnala un problema".
